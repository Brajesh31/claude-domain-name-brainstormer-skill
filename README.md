# DomainNameBrainstormer

Develops distinctive, usable domain-name directions and evaluates candidates against naming, pronunciation, availability-check, and brand-risk criteria.

## What this skill covers

- Practical guidance for domain name brainstormer workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill for tasks related to domain name brainstormer. Provide the relevant context, constraints, and expected outcome. Review generated changes before applying them.
