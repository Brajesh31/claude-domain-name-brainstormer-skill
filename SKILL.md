# Domain Name Brainstormer

Use this skill to generate and evaluate domain-name candidates for a product, company, project, or personal brand.

## Workflow
1. Establish the audience, offer, positioning, geography, language, tone, and naming constraints.
2. Identify 3-5 naming territories before generating names.
3. Generate candidates across descriptive, suggestive, coined, compound, and founder/brand-led patterns.
4. Screen for spelling, pronunciation, ambiguity, unintended meanings, and obvious conflicts.
5. Score candidates with the rubric in `resources/evaluation-rubric.md`.
6. Provide a shortlist with rationale, trade-offs, and suggested next checks.

## Rules
- Never claim a domain is available unless a live registrar or RDAP check confirms it.
- Treat trademark, company-name, and social-handle checks as separate from domain availability.
- Do not recommend typosquatting, impersonation, or confusingly similar names.
- Prefer memorable, pronounceable names over keyword-stuffed names.
- Explain when a name is too generic, hard to spell, culturally risky, or legally uncertain.

## Output
Include naming brief, naming territories, candidate table, top 5 shortlist, risks, and validation checklist. Use `templates/naming-brief.md` and `templates/shortlist.md` when useful.
